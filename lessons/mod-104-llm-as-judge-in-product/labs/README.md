# Labs for mod-104-llm-as-judge-in-product (LLM-as-Judge in Product Pipelines: Rubrics, Bias Controls, and Judge-Tier Routing)

These labs are guided, hands-on sessions that run entirely on stdlib Python (plus `scipy` / `scikit-learn` / `pyyaml` where noted) with deterministic stub judges — no model API keys, no Docker, no vendor backends. They internalise the chapter mechanics by letting you drive each control through a fixture whose biases, disagreements, and drift sources are injected on purpose. They are complementary to (not a replacement for) the module's five exercises, which take the same artefacts against *your* real surface, rubric, and judge model.

- [`lab-01-bias-controls-on-a-stub-judge.md`](lab-01-bias-controls-on-a-stub-judge.md) — pairs with chapters 01 and 02. Drive **swap-and-average**, **length-adjusted scoring**, and the chapter-02 **three diagnostics** (position-bias flag rate, length correlation of raw scores, swap-vs-raw agreement) through a 20-pair fixture against a deterministic biased judge. End the lab knowing which residual misses each control fixes and which it does not.
- [`lab-02-calibration-statistics-and-bootstrap-cis.md`](lab-02-calibration-statistics-and-bootstrap-cis.md) — pairs with chapter 04. Compute the chapter-04 statistic-per-rubric-shape (Spearman ρ / Kendall τ for ordinal; three-class Cohen's κ + non-tie agreement for pairwise) with **95% bootstrap CIs** and a **per-stratum breakdown** on a 60-item pre-labelled fixture that is designed to make the "aggregate hides a bad stratum" failure mode visible. End with the one-page calibration doc chapter 04 says is non-optional.
- [`lab-03-tier-router-and-drift-monitor.md`](lab-03-tier-router-and-drift-monitor.md) — pairs with chapter 05. Wire three stub judges (frontier / mid / OSS) behind a routing function that respects a per-tier weekly cost cap, run it against 60 decisions, pin a frozen replay set, and inject each of the four chapter-05 drift sources (judge model version, rubric prompt template, input distribution, generator) one at a time — watch the triage name the right source and prescribe the right action. End with the on-call runbook chapter 05 asks for.
