# Labs for mod-103-trajectory-and-tool-eval (Trajectory and Tool-Call Evaluation for Production Agents)

Three labs, one per edge of the chapter-01 **scorer / budget / replay** triad. Each is stdlib-only (no model API, no Docker, no network) and builds on the lab before it; together they drill the vocabulary chapter 02 fixes, the arithmetic chapter 04 defines, and the pin discipline chapter 07 requires. They are deliberately shorter and more guided than the module's exercises — the exercises build the production versions of the scorer, rubric, Inspect task, benchmark audit, and replay harness; the labs make the chapter-level vocabulary physical.

- [`lab-01-per-step-scorer-surgical-edits.md`](lab-01-per-step-scorer-surgical-edits.md) — build a per-step scorer with the chapter-02 name / argument / ordering matchers (including `graphlib.TopologicalSorter`, Level-1/2/3 argument matching, and retry collapsing), then do four surgical edits to a known-good trajectory (`wrong_tool`, `wrong_args`, `bad_order`, `redundant_call`) and watch each verdict fire in isolation. Pairs with chapters 02 and 03. 60–90 min.
- [`lab-02-budget-scorer-and-attribution.md`](lab-02-budget-scorer-and-attribution.md) — compute `over_fraction`, per-family `credit`, and the `min`-across-families `budget_credit` on paper for the chapter-01 bad trajectory, verify with a stdlib budget scorer that reads a versioned price table, then do targeted edits that shift `cost_dominant_span`, `latency_dominant_span`, and `retry_dominant_tool` so the attribution block becomes mechanical in your head. Pairs with chapter 04. 45–60 min.
- [`lab-03-replay-pins-and-bisection.md`](lab-03-replay-pins-and-bisection.md) — materialise the six replay pins (model, sampling, messages, tool returns, environment, harness), build the recorded tool-response table (with the full retry sequence), run a stdlib "replay runner" that reproduces the trajectory without calling a model or executing a tool, confirm the scorer from lab-01 emits byte-identical `flagged_verdicts` on the replay, then walk one deterministic bisect (tightened planner prompt) and show the harness fails closed on a side-effectful tool and flags a model substitution as advisory. Pairs with chapter 07. 60–90 min.
