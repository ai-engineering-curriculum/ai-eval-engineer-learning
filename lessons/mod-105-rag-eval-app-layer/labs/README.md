# Labs for mod-105-rag-eval-app-layer (RAG Evaluation at the Application Layer)

These labs are guided, hands-on sessions that run entirely on stdlib Python with canned JSON / CSV fixtures — no model API keys, no RAGAS / TruLens / DeepEval install, no Docker, no vendor backends. They internalise the chapter mechanics by letting you drive each metric, decision tree, and alert through a fixture whose signals are injected on purpose. They are complementary to (not a replacement for) the module's four exercises, which take the same artefacts against *your* real surface with real retriever / generator / judge calls.

- [`lab-01-retrieval-only-metrics-by-hand.md`](lab-01-retrieval-only-metrics-by-hand.md) — pairs with chapter 02. Compute `recall@k`, `MRR`, and `hit rate@k` by hand on a 10-item canned gold set (3 single-chunk, 4 multi-chunk, 3 out-of-scope), verify the numbers in a ~40-line stdlib scorer, then make surgical edits to the retrieved chunk-id lists — drop a relevant chunk from top-5, push a relevant chunk down the ranking — and watch each metric fire or stay silent the way chapter 02 predicts. End with a concrete read on why all three metrics are needed and why per-slice reporting is non-optional.
- [`lab-02-attribution-decision-tree.md`](lab-02-attribution-decision-tree.md) — pairs with chapter 02. Build the chapter-02 attribution decision-tree logic (`attribute.py`) against four canned score bundles — baseline, retrieval-only regression, generation-only regression, coupling regression, joint (coincident) regression — and walk each scenario through the tree. End the lab able to read a dashboard-shaped set of deltas and name which of the four verdicts the evidence lands on, plus the chapter-05 handoff shape each verdict triggers.
- [`lab-03-diagnostic-dashboard-and-silent-regression.md`](lab-03-diagnostic-dashboard-and-silent-regression.md) — pairs with chapters 03 and 04. Assemble the per-slice × per-metric dashboard (four triad + four diagnostics) from a 24-item canned fixture, then flip the fixture to an "after" state in which every triad cell stays within the noise floor while noise sensitivity on the `distractor_heavy` slice drifts by a paging-worthy amount — the chapter-04 silent-regression catch, in code. Finish with a second seeded regression on the `out_of_scope` slice that only the refusal-quality diagnostic can page on, and write the mod-107-shaped regression report chapter 04 asks for.
